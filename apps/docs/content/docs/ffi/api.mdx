Signatures on this page are extracted from `crates/ffi/include/agent_desktop.h` (ABI major 6). Every `AdResult` function returns `AD_RESULT_OK` (0) or a negative code; read the details with the [last-error accessors](/desktop/ffi/ownership-and-threading#errors). Which call frees which pointer is in [Ownership](/desktop/ffi/ownership-and-threading#ownership).

Sizes and versions of versioned structs are the `AD_*_SIZE` and `AD_*_VERSION` macros in the header. `AD_MAX_STRING_BYTES` (1 MiB) bounds every C string the library reads.

## ABI handshake

```c
// Returns the major ABI version of the loaded library.
uint32_t ad_abi_version(void);

// Checks the header major against the library; call once after loading.
AdResult ad_init(uint32_t expected_major);
```

## Adapter lifecycle

An `AdAdapter` is an opaque token. Create one per process, or one per session.

```c
// Creates a platform adapter with no session; null on failure.
struct AdAdapter *ad_adapter_create(void);

// Creates an adapter scoped to a session id; a null session means none.
struct AdAdapter *ad_adapter_create_with_session(const char *session);

// Destroys an adapter; calls in flight finish, later calls fail with invalid args.
void ad_adapter_destroy(struct AdAdapter *adapter);

// Returns OK when accessibility permission is granted or not required.
AdResult ad_check_permissions(const struct AdAdapter *adapter);
```

## Command-backed JSON entrypoints

Each writes an owned JSON envelope into `*out`; free it with `ad_free_string`, including an `"ok": false` envelope. `*out` is null only on an argument or infrastructure failure.

```c
// Snapshots the app surface selected by AdSnapshotSurface.
AdResult ad_snapshot(const struct AdAdapter *adapter,
                     const char *app,
                     int32_t surface,
                     uint8_t max_depth,
                     bool interactive_only,
                     bool compact,
                     char **out);

// Runs a ref action with the default 5000 ms auto-wait; policy is an AdPolicyKind.
AdResult ad_execute_by_ref(const struct AdAdapter *adapter,
                           const char *ref_id,
                           const struct AdAction *action,
                           int32_t policy,
                           char **out);

// Same, with an explicit auto-wait budget (-1 default, 0 single attempt).
AdResult ad_execute_by_ref_timeout(const struct AdAdapter *adapter,
                                   const char *ref_id,
                                   const struct AdAction *action,
                                   int32_t policy,
                                   int64_t timeout_ms,
                                   char **out);

// Runs the wait command until the condition holds or scope.timeout_ms elapses.
AdResult ad_wait(const struct AdAdapter *adapter, const struct AdWaitArgs *args, char **out);

// Returns the status envelope.
AdResult ad_status(const struct AdAdapter *adapter, char **out);

// Returns the version envelope.
AdResult ad_version(char **out);

// Returns the merged trace timeline of the adapter's session.
AdResult ad_trace_show(const struct AdAdapter *adapter,
                       int32_t limit,
                       const char *event_prefix,
                       char **out);

// Exports the session trace as a self-contained HTML file.
AdResult ad_trace_export(const struct AdAdapter *adapter,
                         int32_t limit,
                         const char *out_path,
                         char **out);
```
