# Support

## Before asking

- Read the [README](README.md) and the skill docs in [`skills/`](skills/) — the per-command reference and platform-specific notes are there.
- Search [existing issues](https://github.com/lahfir/agent-desktop/issues) to see if your question has already been answered.

## Getting help

- **Bug or unexpected behavior** — open an issue via the [issue templates](https://github.com/lahfir/agent-desktop/issues/new/choose). Include the `agent-desktop --version` output, the OS and its version, how you installed it, the command you ran with its full JSON output, and reproduction steps.
- **Feature request** — use the feature-request template in the same link above.
- **AI-agent integration / skill usage** — refer to the README's [For AI agents](README.md#for-ai-agents) section and the `skills/agent-desktop/` reference docs. The same skills are bundled in the binary: `agent-desktop skills get desktop` prints the core guide and `agent-desktop skills get platform` the one for your OS.

## Security vulnerabilities

Do **not** open a public issue for suspected security issues. Report privately via [GitHub private vulnerability reporting](https://github.com/lahfir/agent-desktop/security/advisories/new) and see [SECURITY.md](SECURITY.md) for scope and response.

## Response

This project is maintained by [@lahfir](https://github.com/lahfir) on a best-effort basis. There is no guaranteed response time or SLA.
